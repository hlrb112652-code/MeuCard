Configurações

Uma compra feita após o fechamento entra na fatura seguinte. A data de vencimento de cada parcela fica preservada mesmo que você altere as configurações.

Backup e transferência

Exporte um arquivo JSON e guarde-o em local seguro. Para levar os dados a outro aparelho, instale o app nele e importe o arquivo. A importação substitui os dados atuais do aparelho.

Não há sincronização automática. Limpar os dados do navegador pode apagar as compras locais; faça backups regularmente.
